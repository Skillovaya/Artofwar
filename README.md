# NORTHLINE — Frontier Command

Оригинальный браузерный MMO-прототип о командовании военной базой в северном секторе. Интерфейс и игровой мир придуманы для этого проекта; ассеты существующих игр не используются.

## Запуск

Требуется Node.js **22.13+** (используется встроенный SQLite-драйвер `node:sqlite`).

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`. При первом запуске автоматически создаётся гостевая демо-сессия командира **Командир-09** и заполняется тестовый мир. Новая база SQLite создаётся в `data/northline.sqlite`; путь можно переопределить через `NORTHLINE_DB_PATH`. Игровые данные хранятся на сервере, не в `localStorage`.

Для production-сборки:

```bash
npm run build
npm start
```

## Игровой цикл MVP

1. Выберите здание на интерактивной иллюстрации базы и поставьте улучшение в очередь. Ресурсы списываются сразу, уровни применяются после таймера. Работы можно ускорить за игровые кредиты.
2. Заберите полевой резерв; пассивная добыча продолжает работать, пока игра закрыта.
3. Откройте «Армию», выберите тип подразделения и запустите производство.
4. В «Исследованиях» выберите одну из семи веток технологий.
5. На карте сектора перемещайте обзор, меняйте масштаб и фильтруйте базы, объекты, ресурсы и нейтральные точки.
6. Отправьте разведчика: доклад с примерным гарнизоном, обороной, запасами и сооружениями появится после завершения миссии.
7. Выберите состав ударной группы и атакуйте NPC-объект. Сервер рассчитывает потери, победу, добычу, опыт, рейтинг и захват территории; отчёт остаётся в журнале боёв. Игроки представлены на общей карте — для прототипа PvP-рейд моделирует ответ защитника и сохраняет его состояние.
8. Торгуйте по контрактам, выполняйте постоянные и ежедневные задачи, вступайте в альянсы или создавайте свои, переписывайтесь во внутреннем канале, меняйте дипломатию и сверяйтесь с таблицами лидеров.

## Аккаунт и Web3

Гостевой демо-мир доступен без регистрации. Регистрация принимает никнейм, email и пароль; пароль хранится как `scrypt`-хэш, сервер выдаёт HttpOnly-сессию. При регистрации из демо-профиля текущая база, ресурсы, армия, технологии и достижения копируются в новую серверную учётную запись. После регистрации прогресс хранится в SQLite независимо от браузера.

`CONNECT WALLET` — отдельная необязательная точка интеграции: прототип честно сообщает, что blockchain-провайдер и транзакции пока выключены. Обычная игра не требует кошелька, криптовалюты или покупок; инвентарь и обмен ресурсами доступны игровым аккаунтам.

## Архитектура

- **UI:** Next.js App Router, React, TypeScript, Tailwind CSS и авторские стили стратегического интерфейса.
- **Backend:** Route Handlers (`/api/auth/*`, `/api/game`, `/api/game/action`) отделены от экранов. Все игровые команды валидируются и выполняются на сервере.
- **Persistence:** SQLite через Node.js `node:sqlite`; отдельные таблицы пользователей, сессий, состояний игры, объектов карты, альянсов, состава и чата альянсов, дипломатии, рыночных сделок, боевых отчётов, территорий и уведомлений. Очереди, ресурсы и прогресс аккаунта сериализуются как версионируемое игровое состояние.
- **Масштабирование:** каталог механик и DTO отделены от React-компонентов; слой действий можно заменить сервисом PostgreSQL/Redis и вынести расчёт боёв/очередей в отдельные worker-процессы. Wallet-адаптер не входит в обычный игровой цикл.

## Проверка

```bash
npm run lint
npm run build
```

В MVP все основные игровые действия имеют сетевые состояния ожидания, успеха и ошибки. Тестовая карта включает NPC-базы, город, ресурсные узлы, нейтральные посты и альянс; игровые миры аккаунтов сохраняются между перезапусками сервера.
